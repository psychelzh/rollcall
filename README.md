# 点名器（Rollcall）

一个可直接离线使用的课堂随机点名工具。支持经典与星空两种视图：名单导入、随机抽取、已点名单记录与跨设备续点，都围绕课堂现场的实际操作设计。

[![界面截图](image/screenshot.png)](image/screenshot.png)

在线体验：[点名器在线页面](https://psychelzh.github.io/rollcall/)

> `image/screenshot.png` 是经典视图的旧版截图；星空模式的实际效果请打开页面后点右上角「星空」切换查看。

## 这一版改了什么

| 环节 | 以前 | 现在 |
| --- | --- | --- |
| 名单导入 | 只能手动粘贴，或先传到 GitHub 仓库再联网拉取 | 本地文件拖拽 / 点选，支持 .txt / .csv / .tsv，可一次选多份 |
| CSV 解析 | 按换行硬切，表头和多列会被当成一个「姓名」 | 自动跳过表头、识别姓名列与「班级」列，兼容 BOM、CRLF、引号、逗号/制表符/分号分隔 |
| 导入确认 | 直接覆盖，且会清空已点记录 | 先预览人数、星区、重复项、异常行，再选「追加」或「替换」，默认保留已点进度 |
| 已点名单上传 | 没有对应功能，导出是单向的 | 「传回」把导出的文件重新载入并接续进度；「同步」把提交 GitHub 简化为填仓库 + PAT 两步 |
| 点名界面 | 只有文字滚动 | 新增可切换的「星空模式」：学生是星，点名即点亮，已点的星连成星座 |

## 星空模式

- 一名学生对应一颗星，位置按姓名哈希固定，点名不会让任何一颗星换位置，刷新也不乱跑。
- 未点是暗星；滚动时星光在星群间流转；停止时定格点亮，带辉光与涟漪。
- 已点亮的星按点名先后连成星座线，一学期下来逐步连满。
- **星空模式不占右侧栏**：星图吃满整行宽度；名单区自动收成一行摘要（班级、人数、已点、剩余），点右侧小箭头可随时展开。
- **已点学生的姓名直接标在各自星点旁**，星图本身就是完整的点名记录，不必再看侧边列表。
- 点击未点亮的星可以直接手动标记；命名与增删改到「经典」视图操作（导出、传回、同步、清除也在那里）。
- 星空画布始终是深空底色，课堂投影对比度更高；页面白天 / 夜间主题不影响画布。
- 大号姓名只在滚动与出结果时出现，空闲时星图保持完整可见。
- 星点与标注大小随画布自适应，1920×1080 与 1366×768 投影下都保持可读。

**分组规则**

| 导入时掌握的信息 | 星图表现 |
| --- | --- |
| 一次选多份名单文件（如「6班.txt」「7班.txt」） | 按文件名分星区 |
| 单个文件带「班级」列 | 按该列取值分星区 |
| 只有一个名单、没有任何班级信息 | 全班一片星空 |

班级信息是可选增强，不是必填项。工具不会因为缺班级信息而强行分组或要求补填；导入预览里报几个星区，确认后就是几个。

## 使用方法

1. 打开 `index.html`（双击即可，无需服务器、无需联网），或访问在线页面。
2. 导入名单：把文件拖进「名单输入」上方的虚线框，或点击选择，也可直接粘贴姓名；名单区收起时（星空模式默认收起），把文件拖到页面任意位置也能直接弹出导入预览。
3. 在预览弹窗里核对人数、星区、重复项与异常行，选「追加」或「替换」后确认。
4. 点「开始滚动」再点「停止」抽取一名，重复直到名单结束。
5. 右上角切换「经典 / 星空」，两种视图共用同一份进度；星空模式会自动收起名单区、隐藏右侧栏，把版面全给星图。
6. 已点名单可「复制 / 导出 / 传回 / 同步 / 清除」（经典视图下）；导出后在另一台设备用「传回」接着点。

## 已点名单的两条去路

- **传回（本地文件）**：把之前导出的 `.txt` 拖到已点名单区域，或点「传回」选文件。工具会跳过已存在的姓名、只补入新记录，并同步把这些人从待点名单中移除。适用于换电脑、换浏览器后续点。支持先预览再确认。
- **同步（GitHub）**：点「同步」只需填 `owner/repo` 和 PAT；文件路径、PR 标题、分支名自动生成，需要改时展开「高级设置」。仓库名会记住，PAT 只存在当前标签页的会话存储里，关闭标签页即失效，不写入 localStorage。

> 私有仓库的 PAT 需 `repo` 权限，公开仓库需 `public_repo` 权限。

## 数据与隐私

- 待点名单、已点名单、分组、当前名单名、视图模式、主题保存在浏览器 `localStorage`。
- 从旧版升级时会自动读取 `rollcall_all_names_v1` / `rollcall_called_names_v1` / `rollcall_current_list_name_v1` 并迁移，旧数据只读不删。
- 名单解析全部在浏览器本地完成，不上传任何学生信息；唯一的外部请求是用户主动发起的 GitHub 导入 / 同步。
- 「清空名单」「清除已点名单」不可恢复，执行前会二次确认。

## 技术实现

纯原生 HTML / CSS / JavaScript，无框架、无构建步骤、无外部依赖：

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构、内联 SVG 图标集、各功能弹窗 |
| `styles.css` | 设计 Token、白天/夜间主题、双视图布局、响应式 |
| `script.js` | 存储与 v1 迁移、名单解析、导入预览、点名引擎、Canvas 星空渲染、GitHub 同步 |

分层：状态与存储 → 名单解析 → 导入 / 预览 → 点名引擎 → 视图渲染 → 事件绑定。两种视图共用同一个点名引擎与同一份数据，切换视图不丢进度。

- 图标是一套内联 SVG 描边图标（16 / 20 / 24px），不使用 emoji 作为功能图标。
- 颜色全部通过 CSS 变量引用，星空 Canvas 也从同一套 Token 取色。
- 支持 `prefers-reduced-motion`；开启系统「减少动态效果」时关闭闪烁与涟漪。
- 桌面端页面撑满视口高度、宽度上限 1440px；星空模式下侧栏隐藏、星图独占整行，1920×1080 下可达约 1366×739 的绘制区。窄屏自动改为纵向滚动布局。
- 星图用 `ResizeObserver` 跟随容器尺寸重排，收起名单区、切换侧栏、缩放窗口都会即时重算星点位置与标注字号。

## 二次部署（可选）

Fork 本仓库后在仓库设置里启用 Pages 即可，无构建产物；也可直接把三个文件复制到任意静态托管。
